# Contributing to BYCON

Thank you for your interest in contributing to BYCON!

## Development Environment
- Primary language: Rust
- Package Manager: Cargo
- Please ensure you have the latest stable Rust toolchain installed.

## Coding Standards
1. **Formatting**: All Rust code must be formatted using `rustfmt`. Run `cargo fmt` before submitting any PR.
2. **Linting**: We enforce `clippy` lints. Run `cargo clippy -- -D warnings` to ensure there are no warnings.
3. **Tests**: All new features and bug fixes must be accompanied by comprehensive tests.
4. **Design First**: For major changes, propose a design document in the `docs/` folder or via an issue before writing code.

## Pull Request Process
1. Fork the repository and create your branch from `main`.
2. Ensure your code passes all CI checks.
3. Provide a clear description of the problem and your solution.
4. Await review and address any feedback.
