Node & Miner Quick Commands

Start a mining node with your own coinbase wallet address: 

BYCONN_COINBASE=0xYOUR_WALLET_ADDRESS cargo run --release --bin node

Generate a new wallet & signed transaction: 

cargo run --release --bin byconn-wallet
cargo run --release --bin byconn-cli -- wallet new
