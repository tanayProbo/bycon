Core Protocol

Engineered From Scratch in Rust

Every layer — from cryptographic primitives and Merkle tries to P2P gossip and EVM opcodes — is open-source and verifiable.

⛏

Layered Ethash-Inspired PoW

Blocks require an 8-round sequential Keccak-256 mix-hash meeting a 20-bit leading-zero difficulty target, rewarding miners 3 BYC per block.

⚡

EVM & JSON-RPC 2.0

Stack-based bytecode execution engine with standard eth_* JSON-RPC endpoints compatible with MetaMask, curl, and Web3 tooling.

🔐

Secp256k1 & Merkle Commitments

EIP-155 replay-protected signatures and binary Merkle root commitments for state, transactions, and receipts in every block header.

🌐

Libp2p Swarm & BFT Finality

Decentralized peer discovery via mDNS & Gossipsub paired with a 2/3+ validator quorum BFT finality state machine.

Permissionless Mining

Mine BYC on Any Machine in 60 Seconds

Anyone can join the BYCONN network, generate a non-custodial secp256k1 wallet, and run a full PoW mining node. Every block your node mines credits 3 BYC directly to your coinbase address.

  • ✔ Continuous Bitcoin-style block production
  • ✔ Zero pre-mine lockups — 100% open-source MIT license
  • ✔ Standalone CLI & Wallet binaries included
Get BYCONN v0.1.0
bash — byconn-node 
# 1. Clone & generate your BYC wallet
git clone https://github.com/tanayProbo/bycon.git && cd bycon
cargo run --release --bin byconn-cli -- wallet new
Address : 0x71C...89A

# 2. Start mining blocks (3 BYC reward per block)
BYCONN_COINBASE=0xYOUR_ADDRESS cargo run --release --bin node

Economics

BYC Tokenomics & Specifications

Transparent, deterministic protocol rules enforced by every node on the network.

Ticker & Precision

BYC · 18 decimals (1 BYC = 10^18 wei), matching standard Ethereum denomination.

Issuance Model

3 BYC minted per Proof-of-Work block directly to the winning miner's BYCONN_COINBASE account.

Fee Market

Base transfer cost of 21,000 gas with dynamic transaction fee priority ordering in the mempool.
