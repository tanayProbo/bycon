✎ Why We Drew This Blockchain (Protocol Stuff)

1. Bitcoin-Style Continuous Mining ⛏

Even if nobody is sending transactions, the miner keeps chugging and making new blocks! Set your wallet in BYCONN_COINBASE and collect 3 BYC per block!

2. Layered Ethash-Inspired Math 🧮

We don't just hash once! Every nonce runs through 8 sequential rounds of keccak256(mix || parent_hash || nonce || round) before checking for 0x00000...!

3. Real EVM + Merkle Trees 🌳

Every block header commits to a cryptographic state_root, transactions_root, and receipts_root stored in an embedded sled database.

4. Libp2p Gossip + BFT Quorum 📡

Nodes find friends automatically with mDNS + Gossipsub and can finalize blocks with a 2/3+ validator quorum state machine!

★ How 2 Mine BYC on Your Laptop in 60 Seconds ★

Open your terminal, copy-paste these 3 scribbled spells, and watch the blocks roll in: 

# Step 1: Grab the open-source code
git clone https://github.com/tanayProbo/bycon.git
cd bycon

# Step 2: Make your secret wallet key & address (DON'T LOSE IT!!)
cargo run --release --bin byconn-cli -- wallet new

# Step 3: Start the node & miner (earns 3 BYC per block!)
BYCONN_COINBASE=0xYOUR_WALLET_ADDRESS cargo run --release --bin node

← Pssst! Want to send a transaction? Run: cargo run --release --bin byconn-wallet
